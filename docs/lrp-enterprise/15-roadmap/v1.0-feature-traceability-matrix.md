## How to maintain

1. Update **Implemented** and **Gap** when a slice merges.
2. Keep **Slice IDs** in sync with the completion checklist.
3. Move completed High gaps off this matrix into the [product backlog](product-backlog.md) only when deferred past V1.0.
4. Never mark a row **Shipped** while primary UX still depends on demo session data.
