# Door Hangers

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field  | Value                                              |
| ------ | -------------------------------------------------- |
| Size   | 4" × 9" with standard thumb hole                   |
| Stock  | 14–16 pt matte card                                |
| Finish | Matte; optional soft-touch                         |
| Rule   | Office / commercial placement with permission only |

Do **not** place on residential doors without local solicitation rules review and counsel guidance.

## Placement SOP

1. Confirm permission with office manager / LO manager.
2. Leave 5–10 hangers + one rack card stack + business cards.
3. Log activity in CRM (Section 5) with next follow-up.
4. Never imply loan approval, rate locks, or score guarantees on hangers.
