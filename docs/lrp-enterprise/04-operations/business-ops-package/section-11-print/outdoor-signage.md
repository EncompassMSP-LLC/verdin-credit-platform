# Outdoor & Office Signage

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

Large-format and window pieces for events, partner offices (with permission), and owned locations. All public faces carry the short advisory disclaimer.

---

## Yard / stake signs (18" × 24" typical)

**Use:** Open houses **only with host permission**; community education events; owned property.  
**Not for:** Unauthorized residential solicitation.

| Element  | Spec                                              |
| -------- | ------------------------------------------------- |
| Face     | Navy field + wordmark hero                        |
| Headline | Helping More Borrowers Become Lending Ready.      |
| Support  | Ask about mortgage readiness education            |
| QR       | Large (≥ 2") → event or `/contact`                |
| Footer   | Short disclaimer (≥ 10 pt equivalent at distance) |
| Material | Coroplast + H-stake; UV ink                       |

**File:** `LRP_YardSign_YYYYMM_v#.pdf`

---

## Feather / tear-drop flags

| Element | Spec                                           |
| ------- | ---------------------------------------------- |
| Height  | Vendor standard (e.g. 11.5')                   |
| Copy    | Wordmark + tagline only (readable at distance) |
| Avoid   | Dense body copy; fake score gauges             |
| Base    | Cross base or ground spike per venue rules     |

## Window clings / office glass

| Size options | 12" × 18" · 18" × 24" static cling |
| Audience | Partner offices with written permission |
| Front copy | Wordmark · “Mortgage Readiness Partnership” · QR |
| Note | Removable; no residue; partner brand intact |

Do not obscure required license / regulatory postings.

---

## Wall / lobby posters (18" × 24" or 24" × 36")

One composition:

1. Brand (hero)
2. One headline
3. One short support
4. One CTA + QR
5. Disclaimer strip

**Borrower-safe headline options:**

- A clear plan for “not yet”
- Preparing for the next financing conversation

**B2B headline options:**

- Keep more borrowers in the conversation
- Partner With Us
