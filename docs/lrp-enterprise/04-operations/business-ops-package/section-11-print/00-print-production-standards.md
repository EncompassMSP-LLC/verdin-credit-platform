# Print Production Standards

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field    | Value                                                                    |
| -------- | ------------------------------------------------------------------------ |
| Audience | Design vendors, marketing ops, Partner Success                           |
| Palette  | Navy `#0B1F3A` · Gold `#C4A35A` · Warm paper `#F7F4EF` · Slate `#2C3340` |

---

## 1. Hard rules (every piece)

1. Full name **Lending Readiness Partners** before abbreviation **LRP**.
2. Tagline exact: _Helping More Borrowers Become Lending Ready._
3. Short advisory disclaimer on every public face (≥ 7 pt print).
4. Forbidden: guaranteed approval/funding, fabricated FICO before/after, unsupervised filing, “mortgage score” as a promise.
5. Brand name is hero-level on covers; no competing headline that overpowers the wordmark.
6. Prefer matte finishes; avoid neon “credit repair” aesthetics and purple SaaS gradients.

**Short disclaimer:**

> Lending Readiness Score™ is advisory and not a loan approval or underwriting decision.

---

## 2. Color & file prep

| Spec        | Requirement                                       |
| ----------- | ------------------------------------------------- |
| Color mode  | CMYK for press; sRGB proof for screen review only |
| Bleed       | 0.125" all sides (unless vendor specifies more)   |
| Safe margin | ≥ 0.25" from trim for type / QR / logos           |
| Resolution  | 300 dpi raster; logos as vector PDF/AI/SVG        |
| Fonts       | Outline or embed; keep license proof on file      |
| Soft proof  | PDF/X-1a or PDF/X-4 per vendor                    |

---

## 3. QR & URL standards

| Rule         | Detail                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------- |
| Minimum size | ≥ 0.75" square on print                                                                       |
| Quiet zone   | ≥ 4 modules clear                                                                             |
| Destinations | Prefer branded paths (`/lenders`, `/realtors`, `/resources/partner-kit`, `/contact?intent=…`) |
| Test         | Scan from physical print mock at booth lighting before press run                              |
| Versioning   | Re-test after any URL change; update art                                                      |

---

## 4. File naming

```text
LRP_[Asset]_[AudienceOrVariant]_YYYYMM_v#.pdf
```

Examples:

- `LRP_Flyer_DidntQualify_202607_v1.pdf`
- `LRP_Rack_Realtor_202607_v2.pdf`
- `LRP_Banner_Retractable_A_202607_v1.pdf`
- `LRP_VehicleWrap_PanelMap_202607_v1.pdf`

Source working files: `LRP_[Asset]_YYYYMM_v#.ai` / `.indd` / `.canva` link in vendor brief.

Binary home: `assets/lrp/brochures/`, `assets/lrp/print/`, or kit folder under `assets/lrp/marketing-package/` when delivered.

---

## 5. Vendor brief checklist

- [ ] Audience + use case (desk drop, booth, vehicle, office door)
- [ ] Exact dimensions + fold/die-cut notes
- [ ] Quantity + stock + finish
- [ ] Bleed / safe / QR destinations
- [ ] Claim-library PDF attached
- [ ] Brand style guide linked
- [ ] Proof cycle: soft proof → hard proof (optional) → press
- [ ] Delivery: flat + packed kit counts for Partner Success

---

## 6. Compliance review gate

| Piece type                       | Review before first press |
| -------------------------------- | ------------------------- |
| B2B partner collateral           | Marketing + ops           |
| Borrower-facing flyers / hangers | Marketing + compliance    |
| Vehicle wrap / outdoor           | Marketing + counsel notes |
| Anything with testimonials       | Signed release required   |

Mark any legal language **counsel-review required** before live partner use when not already approved.
