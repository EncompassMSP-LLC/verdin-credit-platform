## Assembly SOP

1. Pull from labeled inventory bins; verify version codes (`YYYYMM_v#`).
2. Confirm disclaimer present on every public piece.
3. Insert audience-correct rack/flyer mix (lender vs realtor vs mixed).
4. Add handwritten sticky with Partner Success owner + booking link (optional).
5. Photograph sealed kit for quality spot-checks weekly.
6. Log kit delivery in CRM with partner org + contact.

## Inventory cadence

| Cadence   | Action                                                     |
| --------- | ---------------------------------------------------------- |
| Weekly    | Count STD kits on hand; reorder at ≤ 20                    |
| Monthly   | Retire outdated versions; archive PDFs under `assets/lrp/` |
| Quarterly | Refresh QR destinations; reprint if URLs changed           |
| Ad hoc    | Co-brand runs only with written approval                   |
