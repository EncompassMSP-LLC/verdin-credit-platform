# Vehicle Wrap

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field   | Value                                                       |
| ------- | ----------------------------------------------------------- |
| Purpose | Field marketing / event transport brand presence            |
| Posture | Institutional navy — not aggressive “credit repair” van ads |
| Review  | Marketing + ops; counsel note before first wrap install     |

---

## Design principles

1. Wordmark is the hero on each major panel.
2. Tagline is the primary message; keep secondary copy minimal.
3. Full-bleed photographic atmosphere optional; prefer solid navy + gold accent rules.
4. No fabricated FICO, “approved,” or guarantee language anywhere on the wrap.
5. Phone / URL / QR only where readable at traffic speed (passenger side + rear preferred for detail).

---

## Panel map (typical sedan / SUV / van)

| Panel            | Content                                              |
| ---------------- | ---------------------------------------------------- |
| Driver door      | Wordmark + tagline                                   |
| Passenger door   | Wordmark + “Mortgage Readiness Partnership” + phone  |
| Rear hatch/trunk | Wordmark + QR (≥ 4") + short URL                     |
| Rear bumper      | Short disclaimer strip (high contrast)               |
| Hood (optional)  | Wordmark only — avoid dense type                     |
| Roof             | Omit or wordmark only (aerial photography / parking) |

Van full-wrap may add one support line on rear:

> Education, strategy, and progress for the next financing opportunity.

---

## Required legal / compliance strip

Place on rear bumper or lower rear door in durable high-contrast type:

> Lending Readiness Score™ is advisory and not a loan approval or underwriting decision. Lending Readiness Partners is not a lender.

Add state-required business identification if applicable (counsel).

---

## Ops SOP

1. Approve panel map against claim library.
2. Soft proof → plotter proof of QR/disclaimer size → install.
3. Photograph all sides; store under `assets/lrp/print/vehicle/`.
4. Revisit copy if phone/URL changes; schedule laminate inspection annually.
5. Do not park wraps in ways that imply residential door-to-door credit solicitation without counsel review.
