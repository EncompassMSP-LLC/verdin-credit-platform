# Video Production Standards

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field    | Value                                        |
| -------- | -------------------------------------------- |
| Audience | Creative, marketing ops, Partner Success     |
| Posture  | Institutional, calm — not credit-repair hype |

---

## 1. Hard rules (every video)

1. Full name **Lending Readiness Partners** before abbreviation **LRP**.
2. Tagline when closing longer pieces: _Helping More Borrowers Become Lending Ready._
3. On-screen short disclaimer for any mention of Lending Readiness Score™ or readiness outcomes.
4. Forbidden: guaranteed approval/funding, fabricated FICO before/after, unsupervised filing, “mortgage score” promises.
5. No real client on camera without signed release + counsel/marketing approval.
6. Composite vignettes must be labeled on-screen or in description.
7. Motion: 2–3 intentional transitions max per short; no particle spam / neon “repair” looks.

**Short disclaimer (burn-in or end card):**

> Lending Readiness Score™ is advisory and not a loan approval or underwriting decision.

---

## 2. Technical defaults

| Spec     | Value                                                           |
| -------- | --------------------------------------------------------------- |
| Master   | 4K or 1080p progressive, 24 or 30 fps                           |
| Aspect   | 16:9 (YouTube / web); 9:16 cutdowns for Reels/Shorts/TikTok     |
| Audio    | Dialogue-forward; music bed under −18 LUFS relative to VO       |
| Captions | Burn-in optional; always deliver .srt / .vtt                    |
| Color    | Navy `#0B1F3A` / gold `#C4A35A` / warm paper `#F7F4EF` UI cards |
| End card | Wordmark + tagline + URL + disclaimer                           |

---

## 3. File naming

```text
LRP_Video_[Asset]_[Aspect]_YYYYMM_v#.[mp4|mov]
LRP_Video_[Asset]_Captions_YYYYMM_v#.vtt
```

Examples: `LRP_Video_PartnerOverview_16x9_202607_v1.mp4`

Binary home: `assets/lrp/video/`.

---

## 4. Talent & locations

| Prefer                                       | Avoid                                  |
| -------------------------------------------- | -------------------------------------- |
| Named Partner Success / LO-facing presenters | Aggressive “guru” energy               |
| Office / porch / calm homeownership B-roll   | Shame imagery, destroyed credit tropes |
| Clear VO with dignity-first language         | Urgency scams, countdown timers        |

---

## 5. Review gate before publish

- [ ] Claim-library pass (script + on-screen text)
- [ ] Disclaimer present
- [ ] Captions accurate
- [ ] Description + chapters claim-safe
- [ ] Thumbnail: brand-forward; no fake score gauges
- [ ] CTA matches audience (kit / briefing / contact — not “get approved”)
