# Broker / Branch Dashboard (spec)

**Lending Readiness Partners**

| Field    | Value                                      |
| -------- | ------------------------------------------ |
| Audience | Broker-owner, branch manager, lender_admin |
| Scope    | All LOs under the partnership org          |

## Widgets

| Widget                   | Content                                                   |
| ------------------------ | --------------------------------------------------------- |
| Company pipeline summary | Counts by stage (dashboard-summary)                       |
| LO leaderboard           | Referrals 30d / active / mortgage-ready (no score claims) |
| Stall report             | Referrals with no touch >7 business days                  |
| Training coverage        | % LOs with Quick Start ack                                |
| Monthly trend            | Referrals + hand-backs sparkline                          |

## Actions

- Export weekly/monthly report
- Open referral detail
- Invite LO / resend Quick Start

## Compliance

Aggregate rates only in exports shared externally; no cross-tenant benchmarks.
