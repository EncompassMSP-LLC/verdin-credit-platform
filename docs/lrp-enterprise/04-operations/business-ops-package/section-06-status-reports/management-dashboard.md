# Management Dashboard (LRP internal)

**Lending Readiness Partners**

| Field    | Value                                        |
| -------- | -------------------------------------------- |
| Audience | LRP leadership / Partner Success managers    |
| UI       | `apps/lrp-web` `/crm/` reporting + staff ops |

## Widgets

| Widget           | Content                               |
| ---------------- | ------------------------------------- |
| Book of partners | Active / Engaged / At-risk counts     |
| Referral funnel  | Company-wide stage mix                |
| Owner workload   | Referrals & partners per rep          |
| SLA breaches     | Ack >2d, silent >7d                   |
| Complaint queue  | Open complaints (Section 3)           |
| Enablement       | Training completion %                 |
| Revenue ops      | **[If applicable — counsel/finance]** |

## Cadence reviews

- Mon: SLA & stalls
- Month-end: partner scorecards
- Quarter: portfolio QBR prep

## Data rules

- No fabricated outcome metrics
- Client PII minimized on management tiles (counts + IDs)
- Cross-tenant marketplace metrics: never
