## B. Service overview

### Who we are

Lending Readiness Partners (LRP) helps consumers organize credit-related and documentation work that often affects mortgage readiness conversations.

### What we provide

| Service area            | What it means                                                      |
| ----------------------- | ------------------------------------------------------------------ |
| Consultation            | Structured review of goals, concerns, and available information    |
| Roadmap                 | Prioritized tasks with clear ownership (you / LRP / partner)       |
| Document coaching       | Checklists and secure collection guidance                          |
| Staff-mediated disputes | Where appropriate: prepare and track with human review before send |
| Progress tracking       | Milestones and advisory Lending Readiness Score™                   |
| Partner visibility      | Status updates when you authorize them                             |

### What we do not provide

- Loan origination, underwriting, or funding
- Guaranteed score increases or “wipe your credit” outcomes
- Unsupervised / fully automated bureau filing
- Legal conclusions that an item is a proven FCRA violation (without counsel)
- Advice to use a specific lender as a condition of our service

### Authorizations

## C. Client roadmap

Illustrative path — **your timeline will differ**. Creditors and bureaus control their own response times.

```text
1. Welcome & intake
2. Consultation & advisory analysis
3. Document completion
4. Priority actions (disputes, utilization, collections strategy, etc.)
5. Monitoring & check-ins
6. Mortgage-ready hand-back to your loan officer
7. Your lender’s process (owned by your lender)
```

### Milestone table (fill at consultation)

| Milestone                   | Target window | Owner         | Status |
| --------------------------- | ------------- | ------------- | ------ |
| Intake complete             |               | Client + LRP  |        |
| Consultation done           |               | LRP           |        |
| Docs received               |               | Client        |        |
| Priority plan agreed        |               | Joint         |        |
| Mid-point review (≈30 days) |               | LRP           |        |
| Extended review (≈60 days)  |               | LRP           |        |
| Mortgage-ready review       |               | LRP + Partner |        |

### Your commitments

- Provide accurate information
- Upload documents securely and on time
- Complete assigned tasks
- Tell us about major life/income changes
- Ask questions when something is unclear

### Our commitments

- Clear explanations without hype
- Documented plans
- Staff review before dispute sending
- Respectful communication
- Honest updates when something is blocked
