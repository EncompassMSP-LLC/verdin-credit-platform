# Record Retention Policy

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field  | Value                               |
| ------ | ----------------------------------- |
| Status | **DRAFT — counsel review required** |
| Owner  | Compliance / Ops                    |

---

## 1. Purpose

Define how long LRP retains business and consumer records, and how disposal is handled.

## 2. Retention schedule (baseline — customize with counsel)

| Record type                                | Retention (baseline)                    | Notes                       |
| ------------------------------------------ | --------------------------------------- | --------------------------- |
| Client service file (intake, plans, notes) | **[7 years]** after close/last activity | Align with state/FCRA needs |
| Consumer authorizations / disclosures      | **[7 years]**                           | Keep with client file       |
| Dispute packets & send logs                | **[7 years]**                           | Staff-mediated audit trail  |
| Partner agreements                         | **[7 years]** after termination         |                             |
| Complaints & resolutions                   | **[7 years]**                           |                             |
| Marketing consents / SMS logs              | Per TCPA/state + **[4–7 years]**        |                             |
| Security incident records                  | **[7 years]**                           |                             |
| Financial / tax records                    | Per accountant / law                    |                             |

## 3. Holds

Legal holds suspend destruction until released by counsel.

## 4. Disposal

Secure delete / shred; certify vendor destruction where used. No disposal of records under hold.

## 5. Review

Annual review of schedule; update when products or laws change.
