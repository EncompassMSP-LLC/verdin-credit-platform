# Information Security Policy (Internal)

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field    | Value                                              |
| -------- | -------------------------------------------------- |
| Status   | **DRAFT — counsel / security review required**     |
| Audience | Employees, contractors, vendors with system access |
| Owner    | [Security / Ops lead]                              |

---

## 1. Purpose

Protect confidentiality, integrity, and availability of client, partner, and company data.

## 2. Scope

All systems used for LRP operations: email, CRM, partner/client portals, document vault, laptops, and cloud vendors.

## 3. Principles

1. Least privilege access
2. Need-to-know for consumer data
3. Encryption in transit (TLS) and at rest where supported
4. No SSN/full credit PDFs via personal email
5. Audit logging for access to sensitive client records

## 4. Access control

| Control        | Requirement                                    |
| -------------- | ---------------------------------------------- |
| Accounts       | Unique user IDs; no shared passwords           |
| Authentication | Strong passwords; MFA for production systems   |
| Offboarding    | Access revoked same day as separation          |
| Partners       | Portal roles limited to their referred clients |

## 5. Acceptable use

- Business use of client data only
- No storage of client PII on unmanaged USB drives
- Screen lock when unattended
- Report suspected incidents immediately

## 6. Incident response (summary)

1. Contain (revoke access, isolate system)
2. Notify Security/Compliance lead
3. Preserve logs
4. Assess notification duties (counsel)
5. Remediate and document

## 7. Vendors

Vendors handling personal data require written agreements covering confidentiality and security expectations.

## 8. Training

Security awareness at hire and at least annually; RESPA/privacy refreshers for partner-facing staff.

## 9. Exceptions

Documented approval by Security owner; time-bounded.

## 10. Review

Policy reviewed at least annually or after material incidents.
