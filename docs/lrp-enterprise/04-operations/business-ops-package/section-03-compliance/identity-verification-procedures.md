# Identity Verification Procedures

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field    | Value                                  |
| -------- | -------------------------------------- |
| Status   | **DRAFT — compliance review required** |
| Audience | Intake staff / advisors                |

---

## 1. Purpose

Reasonably verify that the person engaging services is who they claim to be before accessing sensitive credit workflows.

## 2. Standard verification (baseline)

At intake / first consultation:

1. Collect government photo ID (DL / state ID / passport) via secure upload or in-person review
2. Match name to intake form (document nicknames / prior names)
3. Confirm contact channels (email/SMS OTP or callback where available)
4. Record verification method, reviewer, and date in the client file

## 3. Enhanced verification (triggers)

Use additional checks when:

- Identity theft / mixed-file concerns reported
- Conflicting identifying information
- High-risk document anomalies
- Third party claims to act for the consumer without clear authority

Enhanced steps may include: knowledge-based questions from file, secondary ID, written authorization for representatives, or delay of bureau actions until cleared.

## 4. Representatives / POA

Do not discuss file details with third parties without documented authority. Store POA/auth in vault.

## 5. Failures

If identity cannot be reasonably verified: pause dispute sending; escalate to Compliance; notify client of needed steps. Do not fabricate verification.

## 6. Logging

Never store full SSN in tickets/email. Reference “SSN on file via secure channel” when needed.
