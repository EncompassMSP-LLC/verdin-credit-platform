# Dispute Documentation Standards

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field  | Value                                                 |
| ------ | ----------------------------------------------------- |
| Status | **DRAFT — compliance review required**                |
| Rule   | Staff-mediated only; no unsupervised automatic filing |

---

## 1. Purpose

Ensure dispute-related work is accurate, auditable, and claim-library safe.

## 2. Before any dispute is prepared

- [ ] Identity verification complete
- [ ] Valid consumer authorization / FCRA disclosure on file (as applicable)
- [ ] Account(s) identified with enough detail to avoid wrong-item disputes
- [ ] Client narrative reviewed; no coaching to invent facts
- [ ] Supporting docs labeled and stored in vault

## 3. Staff review gate

A qualified reviewer must approve send/export. **AI draft assistance does not replace review.** Reviewer confirms:

- Facts match documents
- No “FCRA violation proven” legal conclusions unless counsel-approved
- No guarantee language in client-facing letters
- Correct bureau/creditor addressee

## 4. Packet contents (typical)

| Element                           | Required       |
| --------------------------------- | -------------- |
| Cover / dispute letter            | Yes            |
| Account identifiers               | Yes            |
| Consumer statement (accurate)     | Yes            |
| Supporting exhibits               | As applicable  |
| ID / proof of address copies      | Per procedure  |
| Send log (method, date, tracking) | Yes after send |

## 5. Prohibited practices

- Filing without client knowledge/authorization
- Disputing items the client says are accurate solely to “try”
- Fabricating evidence or before/after score claims
- Unsupervised bot loops that re-file without human approval

## 6. After send

- Log method/date/tracking
- Update pipeline/milestones
- Schedule follow-up per SOP
- Share status with partner only if authorized

## 7. Quality audit

Sample review monthly: completeness, claim language, authorization presence.

---

_Advisory readiness work supports a lender conversation; it does not guarantee approval or score outcomes._
