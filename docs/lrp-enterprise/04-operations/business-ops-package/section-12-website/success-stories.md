# Success Stories

**Lending Readiness Partners**  
_Helping More Borrowers Become Lending Ready._

| Field   | Value                                                               |
| ------- | ------------------------------------------------------------------- |
| Surface | `/stories` (planned) and/or `/blog` series                          |
| Rule    | **Fictional composites** unless a signed testimonial release exists |

---

## 1. Hard rules

1. No fabricated before/after FICO or bureau scores.
2. No “we got them approved / funded” outcomes presented as LRP decisions.
3. Prefer process outcomes: plan clarity, task completion, partner visibility, return to LO conversation.
4. Label composites: “Composite vignette for illustration—not a specific client result.”
5. Real testimonials require signed release + counsel/marketing approval before publish.

---

## 2. Story template

| Block          | Content                                                               |
| -------------- | --------------------------------------------------------------------- |
| Title          | Dignity-first; no score-bait                                          |
| Audience tags  | Lender · Realtor · Borrower                                           |
| Situation      | “Not yet” / docs / utilization / collections (high level)             |
| Actions        | Education, tasks, staff-mediated steps where relevant                 |
| Partner role   | LO / realtor stayed in the loop                                       |
| Result framing | Better prepared for the next financing conversation — not an approval |
| Disclaimer     | Short + composite label                                               |

## 4. Placement

| Channel                    | Use                                                          |
| -------------------------- | ------------------------------------------------------------ |
